Broker-admin can read its context/sharing and request own user/permission operations; broker-user and broker-readonly can read context/sharing. ## Transactional permission command slice

Implemented the preceding boundary detail with SqlCommandBoundary.ExecuteAuthorizedAsync. Its required callback runs after the command lock but before any receipt lookup/hash/replay, and holds authorization locks through commit. Existing callers retain ExecuteAsync unchanged. AgencyPermissionService uses it for own broker-admin/internal-admin requests and independent internal approve/reject/revoke. Agency serialization, exact stored roles/active identity, target membership and current agency state apply before replay. New effects check proper ETags; audit, agency activity, agency RowVersion and receipt commit atomically. Revocation also rotates every agency user's security stamp and revokes live sessions; it remains available during suspension. SQL creates grants on approval, not a second service insert.
