## User lifecycle slice

Commit **ee5db25** adds AgencyUserLifecycle.Edit/Deactivate/Reactivate with internal authorization before replay, scoped user lookup, user ETag and agency-first locks. Edit accepts only display name and one of the three broker roles. Role updates mutate the existing grant atomically, rotate the stamp and revoke sessions. Concurrent demotion/deactivation cannot remove the last active broker administrator. Deactivation preserves credentials/history and revokes open invitations plus sessions. Reactivation never restores old sessions or invitations: credentialed users return active only under an active agency; users without credentials receive a new staged draft invitation or fresh active-agency issued invitation. Invalid issuance configuration rolls back all state, including user RowVersion. Suspended agencies cannot reactivate users.
